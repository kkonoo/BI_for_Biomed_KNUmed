# Bioinformatics for Biomedical students @ KNUmed

https://kkonoo.github.io/BI_for_Biomed_KNUmed/

## 다크모드와 EN/KO

- Quarto의 light/dark 테마를 함께 사용하므로 상단의 테마 버튼으로 전환할 수 있습니다.
- 운영체제 색상 설정을 기본값으로 따르며, 사용자가 선택한 모드는 브라우저에 저장됩니다.
- 영문 원문은 `index.qmd`와 `chapters/`, 한국어 문서는 `ko/index.qmd`와 `ko/chapters/`에 있습니다.
- EN/KO 버튼은 현재 페이지의 같은 주차 문서로 이동합니다.
- 언어별 사이드바는 `_quarto.yml`에서 별도로 관리합니다.
- 공용 그림과 스타일은 `assets/`를 함께 사용하므로 한국어 폴더에 복제하지 않습니다.

현재 홈과 W1–W7의 한국어 번역이 모두 완료되었습니다.

별도의 다른 수업 저장소에 같은 EN/KO·라이트/다크 스타일을 적용할 때는 [COURSE_SITE_PLAYBOOK.md](COURSE_SITE_PLAYBOOK.md)의 새 채팅용 프롬프트를 사용합니다.
